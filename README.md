# 👥 HRDepartment

Информационная система для сотрудников отдела кадров.

## Требования
* Windows 10/11.
* Visual Studio 2022 или выше.
* .NET Framework 4.7.2.
* SQL Server LocalDB 17.0 (SQL Server 2025).

---

## Запуск
1. Перейдите в папку `HRDepartment`
2. Откройте решение `HRDepartment.sln` с помощью Visual Studio.
3. Дождитесь восстановления NuGet-пакетов.
4. Выполните сборку решения.
5. Нажмите `F5` или кнопку **Start**.

> [!WARNING]
> Для корректной работы проекта требуется SQL Server LocalDB 17.0 (SQL Server 2025).
>
> Проверить версию экземпляра MSSQLLocalDB можно командой:
> ```bash
> sqllocaldb info MSSQLLocalDB
> ```
>
> Если возникают проблемы с экземпляром, выполните пересоздание:
> ```bash
> sqllocaldb stop MSSQLLocalDB
> sqllocaldb delete MSSQLLocalDB
> sqllocaldb create MSSQLLocalDB
> sqllocaldb start MSSQLLocalDB
> ```

- Редактирование и удаление курсов

### Вакансии
- Создание, редактирование и удаление вакансий
- Фильтрация вакансий по статусу
